# Demo 实测报告

验证日期：2026-10-24（Asia/Shanghai）。当前版本已达到本机交互演示程度。
使用真实模型、真实索引和公开来源数据，未使用预写答案替代推理。

## 环境与数据

- Apple Silicon，16 GiB 内存，Python 3.11；网页与模型仅监听本机回环地址。
- 生成模型：Qwen3-4B-Instruct-2507，MLX 4-bit；revision `50d427756c6b1b2fe0c0a10f67fbda1fc8e82c1b`。
- 检索：本地 BGE-large-zh-v1.5、BM25、RRF、BGE-reranker-base；模型固定版本见配置。
- 7 份公开来源文档（6 DOCX、1 文本层 PDF），126 个片段，2 条真实公开采购项目台账。
- 5 页 FastAPI 官方中文文档和引用代码从固定 commit 下载；2 份政府采购公告使用已核对网页摘录。
  转换文档不冒充原始合同。来源、处理方式与许可见 [公开数据说明](../public-data/README.md)。
- 20 道 QA（18 道有依据，2 道拒答）和 8 项 Agent 任务；18 条参考证据完成来源、解析、索引三层定位。
  这是助手来源核对，`human_reviewed=false`、`formal_acceptance=false`。

## 已修复的问题

1. 合并同章节、同页面的连续段落，避免一个句子一个片段；保留 Python 代码缩进。
2. 金额用 Decimal，台账工具支持严格大于/小于，避免模型靠加减 1 猜测边界。
3. 摘要支持唯一文件名匹配；有歧义或错误目录时拒绝错误匹配。
4. 网页单工具回答通过证据处理节点：台账精确渲染字段，知识回答复用 RAG 引用校验，摘要沿用工具结果。
   草稿由最终答案替换，不把未经处理的草稿保留到 SQLite 对话历史。
5. Demo 检索可优先保留精确匹配的子章节证据，避免“必选/可选”混淆；文档总标题不参与该优先规则。
   保留相关性阈值及显式过滤，不改正式 A–D 默认配置。
6. 启动器处理端口复用，退出时清理自身模型子进程；网页提供串行忙状态和错误反馈。

修复过程中保留了失败实测。例如 `20261023T163654Z` 的 QA-004 关键词通过，
但回答错误地把 `None` 当作必选声明。这说明关键词命中和引用格式正确不足以证明语义忠实。
该轮发现的泛化标题误提升已修复；最终结果见下表，早期记录未覆盖。

### 输出差异复核

- QA-016 与 AG-007 输出 `168.6792 万元`，期望字符串是 `168.679200`；两者数值相等。
  原始严格检查仍为失败，未通过修改期望值抹平差异。
- AG-005 使用查询 `FastAPI HTTPException 使用方式`，AG-006 使用 `FastAPI 必选查询参数`，
  两者均附 `doc_type=接口说明书`。与期望参数不完全相同，但实际召回的文档类型和内容正确。
- 最终 QA-004 的代码为 `needy: str`、没有默认值；AG-006 明确说明无默认值为必选、`None` 为可选。
  两条都召回了“如果要把查询参数设置为必选，就不要声明默认值”的原文证据。
- 台账输出保留人民币元精度与来源，未公开负责人返回“未公开”。两份摘要的关键金额、编号、日期
  已与公告摘录复核；海口履约开始早于签订日期的源数据差异予以保留。

上述为助手复核记录，不能替代独立人工评审，不计算正式人工任务完成率。
